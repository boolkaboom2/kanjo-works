# KANJO WORKS — Fullstack JDM Tuning Platform

## Описание проекта
Веб-приложение для тюнинг-ателье в стиле JDM. Проект выполнен в рамках проектной деятельности по веб-разработке.

## Используемые технологии
- **Frontend:** Vanilla JS, HTML5, CSS3 (адаптивная верстка, анимации, кастомный видеоплеер).
- **Backend:** Node.js, Express.js.
- **База данных:** PostgreSQL (хранение данных на облачном хостинге Render.com).
- **Аутентификация:** JWT (JSON Web Tokens) + bcrypt (хэширование паролей).
- **Интеграции:** Telegram Bot API (CRM-уведомления с inline-кнопками).

## Архитектура и безопасность
1. **Серверная авторитетность:** Все расчеты цен и валидация данных происходят на сервере. Клиент не может подделать цену.
2. **Защита от SQL-инъекций:** Используются параметризованные запросы (`$1, $2`).
3. **Rate Limiting:** Ограничение запросов для защиты от DDoS и спама.
4. **Хэширование паролей:** Пароли не хранятся в открытом виде.
5. **Email-верификация:** Подтверждение аккаунта через код.

## API Endpoints
- `POST /api/auth/register` — регистрация.
- `POST /api/auth/login` — авторизация (JWT).
- `GET /api/cars` — получение списка машин.
- `POST /api/book` — создание заявки.
- `GET /api/admin/bookings` — получение заявок (защищено паролем).
- `POST /api/telegram-webhook` — Webhook для кнопок Telegram.

## Как запустить локально
1. Клонировать репозиторий.
2. Выполнить `npm install`.
3. Создать файл `.env` с переменными окружения (DB_URL, Telegram_Token).
4. Запустить `node server.js`.
