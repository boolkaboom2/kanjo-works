# KANJO WORKS — Fullstack JDM Tuning Platform

## Описание проекта
Веб-приложение для тюнинг-ателье в стиле JDM. Проект выполнен в рамках проектной деятельности по веб-разработке. Включает клиентскую часть (каталог, конфигуратор, личный кабинет) и защищенную админ-панель.

## Технологии
- **Frontend:** Vanilla JS, HTML5, CSS3 (адаптивная верстка, кастомный видеоплеер, Scroll Reveal анимации).
- **Backend:** Node.js, Express.js.
- **База данных:** PostgreSQL (хостинг Render.com).
- **Аутентификация:** JWT (JSON Web Tokens) + bcrypt (хэширование паролей).
- **Уведомления:** Telegram Bot API (inline-кнопки для связи с клиентом).

## Безопасность (Реализовано)
1. **JWT-авторизация:** Доступ к API закрыт токенами с ролями (клиент/админ).
2. **Защита от SQL-инъекций:** Все запросы параметризованы (`$1, $2`).
3. **Rate Limiting:** Ограничение количества заявок (защита от спама).
4. **XSS-защита:** Все пользовательские данные экранируются перед выводом (функция `escapeHTML`).
5. **CORS:** Разрешены запросы только с доверенных доменов.
6. **Helmet:** Установлены базовые HTTP-заголовки безопасности.

## API Endpoints (Основные)
- `POST /api/auth/register` — регистрация (с отправкой кода).
- `POST /api/auth/login` — авторизация (JWT).
- `GET /api/cars` — список машин.
- `POST /api/book` — создание заявки (с уведомлением в TG).
- `PUT /api/user/profile` — обновление профиля.
- `POST /api/admin/login` — вход в админку.
- `GET /api/admin/bookings` — получение заявок (JWT Admin).

## Как запустить локально
1. Клонировать репозиторий.
2. Выполнить `npm install`.
3. Создать файл `.env` с переменными: `DATABASE_URL`, `JWT_SECRET`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`, `ADMIN_USER`, `ADMIN_PASS`.
4. Запустить `node server.js`.
